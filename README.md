# Kutuphane
kütüphane takip uygulaması 


Genel olarak okul vb ortamlarda kitap takibinin yapılabilmesini kolaylaştırmak amaçlanmıştır.
Ticari olarak kullanılamaz 

Uygulama hala geliştirme aşamasındadır 

Uygulamayı kullanmak için ilk açılışta admin şifresi belirlemenli ve bu admin şifresi kullanıcı eklemek için kullanılmalı
kullanıcı eklendikten sonra sol taraftan kullanıcı girişi yaparak uygulama kullanılabilir 

bu özelliğin amacı sağlıklı bir aktivite kaydı tutabilmek oldugu için işlem yapmak için kullanıcı girişi zorunlu tutulmuştur 

admin şifresi değiştirilemez ilk açılıştaki şifreyi unutmadıgınızdan emin olun 

normal kullanım süresince şifre gerekmemektedir
